# Contributing

## Commit style

Use Conventional Commits when possible.

Examples:

- `feat: add trojan renderer`
- `fix: reject invalid vless route range`
- `docs: clarify keys.yaml override order`

Release Please reads commits merged into `main` and maintains the version, release PR, and
`CHANGELOG.md`. Use `feat` and `fix` for user-visible changes; other Conventional Commit
types remain available for documentation, tests, builds, and maintenance.
